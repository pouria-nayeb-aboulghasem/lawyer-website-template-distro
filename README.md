# Responsive Portfolio Lawyer Website

A responsive lawyer portfolio website using HTML, Tailwind and JavaScript with mobile first methodology.

## Features

- Responsive Lawyer Portfolio Website Using HTML CSS JavaScript | Mobile First
- Clear and semantic HTML structure.
- Use of CSS variables and modern JavaScript functions.
- Contains animations when scrolling.
- Smooth scrolling in each section.
- Sliding cards in the Cases and Services section.
- External pages linked from the cards in the Cases and Services section.
- Email submission in the Contact section.
- Developed first with the Mobile First methodology, then for desktop.
- Compatible with all mobile devices and with a beautiful and pleasant user interface.
